## 1. Список открытых вопросов

| № | Вопрос | Текущее состояние | Влияние на систему |
|---|---|---|---|
| **Q-01** | Нужна ли персистентная база данных SQLite? | В файле `services/db_service.py` объявлена пустая функция `init_db()`. | Если планируется локальный аудит или сохранение истории перемещений пользователей (`USER_ORIGINAL_OU`), базу нужно структурировать и наполнить таблицами. В противном случае модуль можно удалить. |
| **Q-02** | Планируется ли развитие сервиса печати `print_service.py`? | Метод `generate_print_form` возвращает фиктивное имя файла `"документ_готов.txt"`. | Если требуется печать актов приема-передачи техники или карточек доступа, требуется спецификация шаблонов (docx/pdf). |
| **Q-03** | Требуется ли поддержка нескольких целевых OU для выдачи сертификатов? | В `user_handlers.py` жестко задан путь `OU=notebooklenovo,OU=Bank Divisions,OU=KDB Users,DC=kdb,DC=kz`. | Для пользователей из других филиалов/департаментов этот путь может быть невалидным или нарушать регламент домена. |
| **Q-04** | Необходим ли фоновый мониторинг ПК? | В кэше `__pycache__` обнаружен файл `pc_background_worker.cpython-314.pyc`, однако исходный файл в `services/` отсутствует. | Использовался ли ранее фоновый воркер для проверки компьютеров из функции `get_target_computers()`? Нужно ли его восстанавливать? |

## 2. Вопросы по бизнес-логике
1. **Политика смены временного пароля:** Требуется ли сразу после сброса требовать от пользователя смену пароля при следующем входе в Windows (`pwdLastSet = 0`)?
2. **Лимит выборки при поиске:** Сейчас возвращается до 10 пользователей и до 12 компьютеров. Достаточно ли этого для промышленных масштабов домена?

## 3. Вопросы по инфраструктуре и безопасности
1. **Подтверждение доверия контроллеру домена (CA Certificate):** Планируется ли импорт корневого сертификата корпоративного Центра Сертификации (CA) для валидации SSL в `ldap3.Tls(validate=ssl.CERT_REQUIRED, ca_certs_file=...)` вместо `ssl.CERT_NONE`?
2. **Изолированный контур Zoom:** Нужна ли интеграция с корпоративным TrueConf/Webex/Яндекс.Телемост вместо Zoom, если домен работает в закрытом сегменте?
