## 1. Назначение системы
**Kolins** — специализированный корпоративный Telegram-бот для системных администраторов и инженеров технической поддержки Active Directory (AD DS). Система предоставляет быстрый защищённый интерфейс в Telegram для мониторинга домена, оперативного управления учётными записями пользователей, рабочими станциями, генерации сессий удаленной помощи Zoom и логирования всех действий в аудит-канал.

## 2. Бизнес-цели и решаемые задачи
- **Снижение времени реакции техподдержки (Time-to-Resolve):** возможность разблокировать пользователя, сбросить временный пароль или переместить в OU сертификатов за считанные секунды с мобильного устройства без подключения по RDP/VPN к контроллеру домена.
- **Безопасность и аудит:** фиксация действий каждого администратора с отправкой структурированных карточек в выделенный аудит-чат (`LOG_CHAT_ID`).
- **Автоматизация типовых сценариев:**
  - Подготовка рабочей станции/пользователя под выдачу локальных сертификатов (перемещение в OU `notebooklenovo` и последующий автоматический возврат в исходный OU).
  - Проверка доступности рабочих станций по ICMP-пингу и определение активной WMI-сессии пользователя на машине.
  - Мгновенная генерация корпоративных конференций Zoom для сессий удаленной помощи.

## 3. Ключевой функционал
1. **Управление учётными записями пользователей AD:**
   - Поиск по имени, логину и атрибутам через LDAP ANR (*Ambiguous Name Resolution*) с отказоустойчивым поиском по маске `name=*...*`.
   - Просмотр карточки сотрудника (ФИО, статус активности, отдел, email, телефон, рабочий кабинет, DN).
   - Сброс пароля (по защищенному TLS/StartTLS протоколу).
   - Разблокировка учётной записи (обнуление `lockoutTime`).
   - Перемещение пользователя в OU `notebooklenovo` и безопасный откат в исходное OU по кнопке.
2. **Управление рабочими станциями AD:**
   - Поиск компьютеров по имени и описанию (`name`, `description`).
   - Карточка компьютера с оперативной диагностикой: ICMP-пинг и определение текущего залогиненного пользователя через WMI/PowerShell.
   - Перемещение рабочей станции в контейнер ноутбуков (`TARGET_PC_OU = "OU=KDB notebooklenovo,OU=KDB Nout,DC=kdb,DC=kz"`).
   - Удаление учётной записи компьютера из Active Directory с подтверждением в UI.
3. **Обзор домена и метрики:**
   - Быстрый сбор статистики по домену: общее число пользователей, количество активных и отключенных аккаунтов, общее число ПК.
4. **Интеграция Zoom:**
   - Автоматическое создание сессий Zoom через Server-to-Server OAuth API с возвратом интерактивной карточки и кнопки быстрого копирования ссылки.
5. **Безопасность и UI:**
   - Ограничение доступа по `ADMIN_IDS` на уровне миддлвара.
   - Автоматическое удаление сообщений пользователей для чистоты диалога (`DeleteUserMessageMiddleware`).
   - Современный Rich UI Telegram Bot API с таблицами, спойлерами `<details>` и стилизованными кнопками.

## 4. Глоссарий терминов

| Термин | Описание |
|---|---|
| **AD DS (Active Directory Domain Services)** | Служба каталогов Microsoft для централизованного управления учётными записями, компьютерами и политиками домена. |
| **ANR (Ambiguous Name Resolution)** | Механизм Active Directory для быстрого комплексного поиска объектов по частичным совпадениям (DisplayName, sAMAccountName, GivenName, SN и т.д.). |
| **OU (Organizational Unit)** | Подразделение в иерархии каталога Active Directory. |
| **DN (Distinguished Name)** | Уникальное имя объекта в каталоге LDAP, однозначно определяющее его путь в дереве домена. |
| **StartTLS** | Расширение протокола LDAP, позволяющее переключить открытое соединение (порт 389) в шифрованный TLS-канал. |
| **FSM (Finite State Machine)** | Машина состояний в aiogram для управления пошаговыми диалогами с пользователем (поиск, ввод темы встречи). |
| **WMI (Windows Management Instrumentation)** | Инструментарий управления Windows, используемый ботом через PowerShell для чтения `Win32_ComputerSystem.UserName`. |
