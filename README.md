# Kolins · Active Directory Control Telegram Bot

Корпоративный Telegram-бот для системных администраторов Active Directory (AD DS), обеспечивающий оперативное управление пользователями, диагностику рабочих станций, выпуск сертификатов и аудит действий в Telegram.

## 🚀 Основные возможности
- **Управление пользователями AD:**
  - Поиск по имени и логину через LDAP ANR (*Ambiguous Name Resolution*).
  - Сброс пароля (по защищенному StartTLS каналу).
  - Разблокировка учетных записей (`lockoutTime = 0`).
  - Перемещение в OU для выпуска сертификатов и обратный откат в исходное OU по кнопке.
- **Диагностика и управление ПК:**
  - Поиск рабочих станций по имени и описанию.
  - Проверка доступности (ICMP-пинг).
  - Определение текущего вошедшего пользователя через WMI/PowerShell (`Win32_ComputerSystem`).
  - Перемещение в OU ноутбуков и безопасное удаление учетной записи ПК.
- **Интеграция с Zoom:** Мгновенное создание комнат техподдержки через Zoom OAuth API.
- **Безопасность и Rich UI:**
  - Ограничение доступа по `ADMIN_IDS`.
  - Отправка подробных отчетов действий в чат аудита (`LOG_CHAT_ID`).
  - Форматирование карточек с использованием современного Telegram Rich Message API.

## 🛠 Быстрый старт

### 1. Установка зависимостей
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 2. Настройка окружения
Создайте файл `.env`:
```env
BOT_TOKEN=ваш_токен_бота
ADMIN_IDS=12345678,98765432
LOG_CHAT_ID=-1001234567890

AD_SERVER=192.168.201.15
AD_DOMAIN=kdb.kz
AD_USER=svc_kolins@kdb.kz
AD_PASSWORD=ваш_пароль_ad
AD_SEARCH_BASE=DC=kdb,DC=kz
```

### 3. Запуск бота
```powershell
python main.py
```
